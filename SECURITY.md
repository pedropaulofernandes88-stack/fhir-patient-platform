# Política de segurança e dados

## Relato responsável

Use **Report a vulnerability** na aba Security do GitHub. Não publique credenciais, dados pessoais
ou detalhes exploráveis em issues.

## Limites

O projeto aceita somente dados sintéticos. Não há autenticação, autorização, TLS, criptografia de
campo ou isolamento multi-institucional; por isso ele não deve ser exposto à internet nem receber
dados clínicos reais.

Para uma implantação real, execute avaliação de ameaça, LGPD, controle de acesso por menor
privilégio, gestão de segredos, retenção, backup, observabilidade e testes de segurança.
